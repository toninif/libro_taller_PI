# Plantillas descargables

Estos recursos acompañan los capítulos del libro. Se linkean desde el capítulo correspondiente y, cuando el conjunto esté completo, también desde el capítulo 16.

## Disponibles

- `plan-de-analisis.md`: estructura para definir pregunta, hipótesis, variables, análisis y resultado esperado.
- `diccionario-de-datos.csv`: plantilla para documentar cada variable. Se abre con Excel, LibreOffice o cualquier planilla de cálculo.
- `encuesta-estudiantes-limpia.omv`: base sintética limpia para los análisis de los capítulos 10–14.
- `taller-organizacion-prepost.omv`: base sintética para la t pareada del capítulo 11.
- `arbol-de-decision.md`: guía imprimible para elegir los análisis básicos del libro.
- `checklist-antes-de-recolectar.md`, `checklist-antes-de-analizar.md` y `checklist-antes-de-entregar.md`: controles de diseño, análisis y comunicación.
- `frases-de-reporte-apa.md`: plantillas de redacción para los análisis del libro.

Los CSV fuente y la documentación de los ejemplos están en `datos/`.
