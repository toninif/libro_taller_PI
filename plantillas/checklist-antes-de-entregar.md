# Checklist: antes de entregar

- [ ] La pregunta, hipótesis, variables y análisis cuentan la misma historia.
- [ ] Informé descriptivos antes o junto con el test correspondiente.
- [ ] Expliqué en palabras la dirección del resultado; no dejé solo un valor *p*.
- [ ] Si el resultado no fue significativo, lo informé sin llamarlo “prueba de igualdad”.
- [ ] Informé el estadístico, grados de libertad, valor *p*, tamaño de efecto e intervalo de confianza cuando corresponden.
- [ ] Las tablas y gráficos responden una pregunta concreta y tienen títulos o etiquetas claras.
- [ ] Revisé supuestos, alternativas y decisiones sobre faltantes o filtros.
- [ ] Las citas y referencias siguen APA 7 cuando se usan fuentes.
- [ ] Guardé la base, el diccionario, las transformaciones y el archivo `.omv`.
- [ ] Si comparto la base, quité identificadores y datos personales que no sean necesarios.

El objetivo no es llenar una lista: es poder mostrar cómo llegaste desde una pregunta hasta una conclusión que otra persona pueda revisar.
