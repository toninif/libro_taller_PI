# Checklist: antes de analizar

- [ ] Conservé una copia de la base original.
- [ ] Cada columna de la base coincide con el diccionario de datos.
- [ ] Revisé nombres, tipos, niveles de medida y etiquetas de categorías.
- [ ] Declaré los códigos de faltantes; no los dejé como números reales.
- [ ] Documenté cada recodificación, cálculo o filtro en una columna nueva.
- [ ] Verifiqué cuántos casos entran realmente en el análisis.
- [ ] Pedí descriptivos y un gráfico adecuado para la pregunta.
- [ ] Revisé rangos imposibles, valores extremos y distribución.
- [ ] Elegí el análisis desde la pregunta y las variables, no desde el resultado.
- [ ] Revisé el supuesto relevante y anoté el plan B si corresponde.

Un análisis es reproducible cuando otra persona puede seguir estos pasos y entender por qué entraron esos datos y no otros.
